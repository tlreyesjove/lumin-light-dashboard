Usage — Do

  • Navy for primary text, headers, nav, and primary buttons
  • Amber only as an accent — CTAs, highlights, one data series
  • Light gray page background with white cards, per Sales/Finance/Inventory pillar
  • Status colors reserved strictly for alerts/thresholds (never decorative)
  • One typeface (Inter), varying weight for hierarchy

Usage — Don't

  • Don't use amber as a large background fill — it's an accent, not a base color
  • Don't reuse status amber/red/green for branding or charts unrelated to alerts
  • Don't mix in a second typeface — use weight/size instead
  • Don't default to dark mode — light background is the standard here
Lumin Light is a fictional company built for a personal learning/portfolio project. This guide is meant to be referenced directly by Claude Code when building the dashboard (colors, type, and usage rules above are final for v1).
